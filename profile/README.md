**A friendly Mac app for your OctoPrint 3D printers.** Free and open source.

Every printer at a glance, live cameras, a 3D preview that follows the print, layer alerts, statistics, widgets and more, in a native app built for watching and running prints.

![OctoMac showing a print in progress](https://raw.githubusercontent.com/OctoMac-App/OctoMac/master/docs/screenshots/overview.png)

**[Download OctoMac](https://github.com/OctoMac-App/OctoMac/releases/latest)** for macOS 15 or newer, on Apple silicon and Intel, or install it with Homebrew:

```sh
brew tap octomac-app/tap
brew trust octomac-app/tap
brew install --cask octomac
```
